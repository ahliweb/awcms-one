# ADR-0060 — SAST dengan OpenGrep menggantikan CodeQL di leg `local-ci/security`

- **Status:** Diterima
- **Tanggal:** 28 November 2026
- **Pengambil keputusan:** ahliweb (keputusan pemilik 27 November 2026, standar lintas-portofolio internal DL-098; instruksi pemilik 28 November 2026 untuk menerapkannya di sini)
- **Terkait:** issue [#603](https://github.com/ahliweb/awcms-one/issues/603); [ADR-0021](0021-zero-github-actions-local-ci-with-exact-sha-statuses.id.md) (CI lokal; D7-nya menggambarkan leg CodeQL dan digantikan ADR ini hanya untuk bagian SAST, dan alternatif yang dulu ditolaknya, "Semgrep saja untuk leg keamanan", ditinjau ulang di sini); [ADR-0018](0018-awcms-one-is-a-template-with-build-profiles-and-an-idempotent-init.md) dan [ADR-0024](0024-awcms-one-is-template-only-derived-apps-own-their-backend.md) (repositori ini adalah template; repositori turunan memiliki CI-nya sendiri)

## Konteks

Leg `local-ci/security` menjalankan CLI CodeQL. CLI CodeQL gratis dipakai pada repositori publik, dan repositori ini publik, tetapi ketentuan CodeQL GitHub melarangnya pada codebase yang bukan open source dan di CI tanpa lisensi GitHub Advanced Security berbayar. Repositori yang dibuat dari template ini umumnya privat, dan ia mewarisi `tools/ci/` apa adanya. Pemilik memilih satu jalur SAST untuk setiap repositori portofolio, termasuk yang publik: CodeQL tidak dijalankan di mana pun, baik di workflow, di server, maupun di mesin kerja. Sejak itu leg ini sama sekali tidak dapat dijalankan, sehingga `local-ci/security`, konteks wajib di `main`, tidak dapat dipasang hijau untuk PR mana pun.

ADR-0021 menolak leg keamanan yang hanya memakai Semgrep karena aturan komunitasnya tidak mencapai kedalaman dataflow CodeQL. Trade-off itu kini terpaksa berbalik: tidak ada lagi jalur CodeQL yang berlisensi, dan yang tersisa adalah mesin pola/taint dengan set aturan terpin yang boleh didistribusikan ulang.

## Keputusan

- **D1.** Leg menjalankan tiga pemeriksaan: OpenGrep, gitleaks (image dipin digest, `tools/ci/gitleaks.toml`, tidak berubah), dan `bun audit` (ambang dan `tools/ci/dependency-audit-exceptions.json` tidak berubah). Nama leg dan konteks status tetap `local-ci/security`, sehingga branch protection tidak berubah.
- **D2.** OpenGrep `v2.1.0`, asset `opengrep_linux_x86`, dipin sha256 `d6a68a84c01a3d8ee933f60847decf1b4d0fd7791a26833b32b95922baf28974` (`tools/ci/lib/opengrep-cli.ts`). Binary diunduh ke berkas `.part`, diverifikasi, baru di-rename; binary di cache diverifikasi ulang sebelum setiap pemakaian; digest yang tidak cocok menggagalkan leg.
- **D3.** Aturan adalah salinan `opengrep/opengrep-rules` pada commit `f1d2b562b414783763fd02a6ed2736eaed622efa`: semua aturan `.yaml` dan `.yml` di `javascript/` dan `typescript/` (203 berkas, fixture uji tidak disalin) ditambah `LICENSE` hulu, di `tools/ci/sast/rules/`, dengan git blob id setiap berkas di `tools/ci/sast/rules.lock`. Aturan workflow (`yaml/github-actions/`) tidak disalin, karena repositori ini tidak punya `.github/workflows/` di root (ADR-0021). Aturan Semgrep Registry (`p/...`) dan `semgrep/semgrep-rules` setelah 2024-12-13 tidak dipakai. Direktori aturan mempertahankan lisensinya sendiri (Commons Clause di atas LGPL-2.1), dinyatakan di `tools/ci/sast/rules/README.md`; ia tidak berada di bawah lisensi MIT repositori.
- **D4.** Gerbang gagal hanya pada temuan berseverity ERROR yang tidak ada di `tools/ci/security-baseline.json` (dicocokkan lewat id aturan dan path); temuan WARNING dan INFO dihitung di laporan bukti, tidak menggerbangi. Baseline hanya menyusut. Isi adopsinya berasal dari satu scan penuh atas pohon, dijalankan sekali di server CI dengan `bun tools/ci/cli/sast-baseline.ts`, yang menolak berjalan kecuali `tools/ci/sast/ADOPTION-BASELINE-PENDING` ada dan baseline kosong, menulis setiap temuan ERROR, dan menghapus penanda itu. Selama penanda ada, leg gagal tertutup. `BASELINE_CEILING` di `tests/local-ci-baseline.test.mjs` ditetapkan sama dengan jumlah yang dihasilkan dalam commit yang sama; menaikkannya kemudian adalah keputusan yang ditinjau dengan alasan per entri, tidak pernah lewat skrip. Agent tidak pernah menambah entri untuk meloloskan PR-nya sendiri. Entri era CodeQL (rule id CodeQL, yang tidak mungkin cocok dengan temuan OpenGrep mana pun) dihapus; alasannya tetap tercatat di `SECURITY.md`.
- **D5.** Scan berjalan tanpa jaringan setelah unduhan terpin: `--disable-version-check`, hanya aturan tersalin, `SEMGREP_SEND_METRICS=off` (OpenGrep `v2.1.0` menolak opsi `--metrics`, jadi opsi itu tidak dipasang), dan `--jobs` dari `CI_LOKAL_CPUS` (bawaan 5). Pengecualiannya adalah `paths-ignore` milik `.github/codeql/codeql-config.yml` yang lama ditambah direktori aturan; source `apps/cms/**` tetap dalam cakupan. Laporan JSON adalah bukti leg; hasil tidak diunggah ke code scanning GitHub. Laporan milik pembuat baseline adalah artefak antara dan dihapus dalam `finally`.
- **D6.** CodeQL dicabut: `.github/codeql/codeql-config.yml`, pengunduh CLI CodeQL (modul `codeql-cli.ts` di `tools/ci/lib/`, beserta pin versi, checksum, dan query pack-nya), parser SARIF (`sarif.ts` di direktori yang sama), unggahan SARIF, dan opsi `--upload-sarif` milik `bun run ci`. Salinan subtree upstream di `apps/cms/` (`.github/workflows/codeql.yml`, `.github/codeql/`, dan skill triase CodeQL-nya) tidak dijalankan di sini dan tidak diedit; ia mengikuti upstream.

## Konsekuensi

- **Titik buta dibanding CodeQL, diterima:** pencocokan pola dan taint pada pohon sintaks, bukan dataflow seluruh program, sehingga lebih sedikit aliran antar-prosedur ditemukan dan hasil bersih lebih lemah sebagai bukti; salinan aturan beku yang berubah hanya lewat kenaikan yang disengaja; berkas `.astro` tidak dipindai (seperti sebelumnya); tanpa siklus hidup alert dan tanpa tampilan tab Security; hanya temuan ERROR yang menggerbangi.
- Sampai baseline adopsi dibuat dan di-commit, `local-ci/security` merah secara sengaja. PR yang membawa ADR ini di-merge hanya bersama baseline itu.
- Mencabut konteks wajib bernama CodeQL atau setelan code scanning dari setelan repositori adalah tindakan pemilik, bukan bagian perubahan ini; `main` mewajibkan `local-ci/security`, yang namanya tidak berubah.
- Kenaikan versi OpenGrep atau commit aturan adalah perubahan tersendiri: verifikasi digest baru terhadap rilis, salin ulang aturan dan buat ulang `rules.lock`, periksa ulang lisensi aturan, jalankan ulang leg, dan tangani temuan ERROR baru lewat tinjauan baseline, bukan dengan membuat ulang baseline.
- **Rollback:** revert PR yang membawa ADR ini. Itu mengembalikan leg CodeQL, yang tidak boleh dijalankan menurut keputusan pemilik, sehingga rollback hanya untuk diagnosis.
